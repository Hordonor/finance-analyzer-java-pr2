# Фінансовий аналізатор — практична робота 2

Консольний Maven-застосунок читає банківські транзакції з CSV і формує текстові звіти. У моделі `Transaction` Lombok генерує конструктори, getters/setters, `equals`, `hashCode` і `toString`.

## Вимоги та запуск

- JDK 17 або новіший
- Apache Maven 3.9 або новіший

```powershell
chcp 65001
./mvnw.cmd clean test
./mvnw.cmd exec:java
```

Для коректного показу українського тексту у Windows-консолі спочатку перемкніть її на UTF-8 командою `chcp 65001` або запускайте `run.bat`. `.mvn/jvm.config` також задає UTF-8 для JVM.

За замовчуванням програма читає копію навчального CSV `src/main/resources/transactions.csv`. Щоб передати власний локальний файл або URL, можна виконати:

```powershell
./mvnw.cmd exec:java "-Dexec.args=C:\data\transactions.csv 01-2024"
./mvnw.cmd exec:java "-Dexec.args=https://informer.com.ua/dut/java/pr2.csv 01-2024"
```

Формат дати у CSV — `dd-MM-yyyy`; потрібний місяць передається як `MM-yyyy`. Очікуються три стовпці: дата, сума, категорія/опис. Заголовок `Дата,Сума,Категорія` необов'язковий. Значення категорії з комами підтримуються у подвійних лапках.

## Звіти

Програма показує загальний баланс, кількість транзакцій за місяць, до 10 найбільших витрат, найбільшу і найменшу витрату за місяць, а також текстові підсумки витрат за категоріями та місяцями. У гістограмі один `*` означає кожні 1000 грн витрат.

## Структура та призначення класів

- `model/Transaction` — модель окремої транзакції; Lombok усуває шаблонний код доступу до полів.
- `io/TransactionCSVReader` — окремо читає рядки з будь-якого UTF-8 потоку та окремо перетворює рядки CSV на модель. Клас абстрактний, конструктор закритий, методи статичні: стану для екземплярів немає.
- `analysis/TransactionAnalyzer` — статичні розрахунки балансу, періодів і категорій; абстрактний клас не створює зайвих екземплярів.
- `report/TransactionReportGenerator` — статичне форматування і друк звітів; також абстрактний клас без екземплярів.
- `Main` — завантажує дані та послідовно викликає аналіз і формування звітів.

## Самостійна робота

Додано модульні тести читання CSV і пошуку десяти найбільших витрат. Розширення аналізатора знаходить найбільшу/найменшу витрату за місяць і підсумовує витрати за категоріями та місяцями. Текстовий звіт малює зірочки з кроком 1000 грн.
